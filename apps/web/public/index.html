> join omaglobe

Install the plugin: a globe in your omarchy bar that puts your machine on this map while it's online. Off until you switch it on.

omarchy plugin add https://github.com/mark-omarov/omaglobe-plugin --enable
omarchy bar move io.github.mark-omarov.omaglobe --after omarchy.indicators

Hover the middle of your bar to find the globe, then switch it on. source

> about omaglobe

An opt-in map of omarchy users. A community project, not affiliated with omarchy, omacom or 37signals.

privacy

  • The map shows omarchy machines running the omaglobe plugin with sharing switched on. It's off by default. Visiting this site shares nothing.
  • While on, the plugin sends a random install ID (stored hashed) and the city you picked once an hour. It's dropped about an hour after the last one, or right away when you switch it off.
  • No names, accounts, IP addresses, coordinates, cookies or analytics. A city shows only once 3 machines are there, and the map updates once a minute so no one can tell when you joined.
  • Cloudflare hosts the site and sees connections, as any host does.
